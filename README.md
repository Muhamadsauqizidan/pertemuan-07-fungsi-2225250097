## Fungsi Program

2. Menghitung luas segitiga.
3. Menghitung jumlah 1 sampai n.
4. Menghitung faktorial.

## Hasil Pengujian
- Luas persegi panjang (8, 5) = 40
- Luas segitiga (10, 6) = 30.0
- Jumlah 1 sampai 10 = 55
- Faktorial 5 = 120
- Faktorial 0 = 1
